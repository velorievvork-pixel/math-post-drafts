# Morning post — 2026-11-26

**Topic:** The Kakeya set conjecture. A Kakeya set is a set in n-dimensional
space that contains a unit line segment pointing in every possible
direction. Such sets can have measure (area/volume) zero — the classical
Kakeya needle problem (Besicovitch, 1919) showed a needle can be rotated
180° within a region of arbitrarily small area. But the modern Kakeya set
*conjecture* asks about dimension rather than measure: does every Kakeya
set still have to have full Hausdorff/Minkowski dimension n, even though
its measure can be zero? In February 2025, Hong Wang and Joshua Zahl
posted a 127-page proof on arXiv resolving this for n = 3 (the hardest
previously-open case), showing every 3D Kakeya set has full dimension 3.
Widely covered as a "once-in-a-century" result (Quanta, Scientific
American, NYU, UBC, IAS).

Sources checked via web search: Quanta Magazine
("Once-in-a-Century Proof Settles Math's Kakeya Conjecture", 2025-03-14),
arXiv 2502.17655 (Wang & Zahl, Feb 2025), NYU Courant news, UBC Math news.
