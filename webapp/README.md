# Учись со мной

Сайт-репетитор: присылаешь тему, фото конспекта/учебника, PDF или текстовый файл —
получаешь персональный урок, а в конце — тест, который проверяет, что материал
действительно усвоен. Если есть слабые места, сайт объясняет их ещё раз и даёт
пройти тест заново.

## Как это устроено

- Бэкенд (`server.js`, Express) принимает тему и файлы, отправляет их в Gemini API
  (модель `gemini-3.6-flash`) и получает урок в структурированном виде (JSON, через
  `responseSchema` — модель не может ответить произвольным текстом). Урок рассчитан
  на 30-45 минут вдумчивого изучения: 8-12 разделов, разобранные примеры и
  практические задачи с решениями.
- Дальше по кнопке генерируется тест примерно на 15 минут: 7 вопросов с вариантами
  ответа + 3 открытых вопроса. Правильные ответы хранятся только на сервере
  (в памяти), чтобы их нельзя было подсмотреть в браузере.
- После ответа сервер сам проверяет вопросы с вариантами и просит Gemini оценить
  открытые ответы по сути, а не по формулировке.
- Если результат меньше 80% — показываются слабые места, можно попросить объяснить
  их ещё раз и пройти новый тест по тому же уроку.

## Запуск

```bash
cd webapp
npm install
cp .env.example .env
# впишите свой ключ в .env: GEMINI_API_KEY=AIza...
npm start
```

Откройте http://localhost:3000

## Деплой на Render

В корне репозитория есть `render.yaml` (Render Blueprint), который описывает сервис
целиком — не нужно ничего настраивать руками, кроме ключа API.

1. Зайдите на https://dashboard.render.com/blueprints и нажмите **New Blueprint Instance**
   (или откройте `https://render.com/deploy?repo=https://github.com/velorievvork-pixel/math-post-drafts`).
2. Подключите GitHub-аккаунт и выберите репозиторий `velorievvork-pixel/math-post-drafts`,
   ветку `claude/learning-website-pjn8to` (или `main`, если ветка уже туда влита).
3. Render найдёт `render.yaml` и предложит создать веб-сервис `learn-with-claude`
   (билд из папки `webapp/`, план Free).
4. Когда попросит — впишите `GEMINI_API_KEY` (это единственный обязательный секрет,
   получить его можно на https://aistudio.google.com/apikey).
5. Нажмите **Apply** — через пару минут сайт будет доступен по ссылке вида
   `https://learn-with-claude.onrender.com`.

Бесплатный план Render "засыпает" после ~15 минут без запросов и просыпается
~30-60 секунд на первый запрос после простоя — для личного использования это нормально,
для постоянной доступности стоит взять платный план.

## Переменные окружения (`.env`)

| Переменная | Обязательна | Назначение |
|---|---|---|
| `GEMINI_API_KEY` | да | ключ Gemini API (aistudio.google.com/apikey) |
| `PORT` | нет | порт сервера, по умолчанию 3000 |
| `GEMINI_MODEL` | нет | модель Gemini, по умолчанию `gemini-3.6-flash` |

## Ограничения

- Данные ученика (уроки, тесты) не сохраняются в базе — всё живёт в памяти процесса,
  пока запущен сервер (тесты автоматически "протухают" через 2 часа).
- Загрузка файлов: до 5 файлов за раз, максимум 10 МБ каждый; поддерживаются
  изображения, PDF и текстовые файлы.
