# Учись со мной

Сайт-репетитор: присылаешь тему, фото конспекта/учебника, PDF или текстовый файл —
получаешь персональный урок, а в конце — тест, который проверяет, что материал
действительно усвоен. Если есть слабые места, сайт объясняет их ещё раз и даёт
пройти тест заново.

## Как это устроено

- Бэкенд (`server.js`, Express) принимает тему и файлы, отправляет их в Claude API
  и получает урок в структурированном виде (JSON).
- Дальше по кнопке генерируется тест: 5 вопросов с вариантами ответа + 2 открытых
  вопроса. Правильные ответы хранятся только на сервере (в памяти), чтобы их нельзя
  было подсмотреть в браузере.
- После ответа сервер сам проверяет вопросы с вариантами и просит Claude оценить
  открытые ответы по сути, а не по формулировке.
- Если результат меньше 80% — показываются слабые места, можно попросить объяснить
  их ещё раз и пройти новый тест по тому же уроку.

## Запуск

```bash
cd webapp
npm install
cp .env.example .env
# впишите свой ключ в .env: ANTHROPIC_API_KEY=sk-ant-...
npm start
```

Откройте http://localhost:3000

## Переменные окружения (`.env`)

| Переменная | Обязательна | Назначение |
|---|---|---|
| `ANTHROPIC_API_KEY` | да | ключ Claude API |
| `PORT` | нет | порт сервера, по умолчанию 3000 |
| `ANTHROPIC_MODEL` | нет | модель Claude, по умолчанию `claude-opus-5` |

## Ограничения

- Данные ученика (уроки, тесты) не сохраняются в базе — всё живёт в памяти процесса,
  пока запущен сервер (тесты автоматически "протухают" через 2 часа).
- Загрузка файлов: до 5 файлов за раз, максимум 10 МБ каждый; поддерживаются
  изображения, PDF и текстовые файлы.
