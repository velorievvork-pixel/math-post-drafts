# math-post-drafts

Scratch storage for the daily math X-post drafting agent. Each run adds an image + short notes under `YYYY-MM-DD/morning/` or `YYYY-MM-DD/evening/`.

## webapp/

A separate project: a small learning website. A person sends a topic, a photo, or a file;
the site (backed by the Claude API) builds a full lesson from it and then quizzes them to
confirm they actually understood it. See `webapp/README.md` for setup and run instructions.
